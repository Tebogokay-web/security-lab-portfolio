# My lab rules

## Cost
- A budget alert is set on my subscription (50%, 80%, 100%).
- The workspace has a daily ingestion cap.
- I stop (deallocate) the VM when I'm not using it. Shutting down from inside Windows still costs money.
- I choose "Common" events when collecting Windows logs, not "All".
- Check current Sentinel pricing and free-trial terms before turning things on.

## Safety
- Only my own lab machines get attacked, and only with fake accounts.
- No real passwords, keys or personal data in this repo.
- I blur or crop my email, student number and subscription ID in screenshots.
- Remote access ports on the VM are limited to my own IP.
